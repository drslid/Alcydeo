The TV receives the complete stream and selects a supported quality and audio track.

Native Cast depends on Chrome, the receiver and the media format. Alcydeo adds no media relay server. Tab casting can use the original site’s player when direct playback is unsuitable.

## Cast the original tab

Return to the original tab, play the video, then use Chrome’s ⋮ menu → Cast, save, and share → Cast… → Sources → Cast tab. Choose your TV. This selector is opened from Chrome’s menu.

Use a Google Cast-compatible receiver on the same local network. If Chrome cannot find it either, check the network, VPN and firewall settings.

## How to cast this player

1. Open your video file in Alcydeo and start playback.
2. Open Chrome’s ⋮ menu → Cast, save, and share → Cast…. This button shows instructions; the receiver picker opens from Chrome’s menu.
3. Under Sources, choose Cast tab, then your TV, for example NVIDIA SHIELD.

Keep this tab open. Use the video controls for playback and Chrome’s Cast control to stop casting. Tab casting can use more CPU than sending a video link.

Files stay on this PC; native Chrome Cast sends media to the selected receiver. Alcydeo does not upload to a hosting service.

支持直接文件以及已测试的未加密 HLS/DASH 变体。兼容性取决于来源访问权限、编解码器和存储空间。受保护媒体会被拒绝。分段处理约需媒体大小三倍的临时空间；并非所有大文件都已验证。

Firefox 153+ 使用独立软件包，不包含 YouTube。Firefox 中不提供 Chrome 标签页录制、Google Cast 或 AirPlay。本地处理取决于浏览器支持的编解码器；Firefox 指南记录实际测试范围。

Chrome 开发 ZIP 包含实验性 YouTube 支持。独立的 Chrome 商店准备包和 Firefox 包均排除 YouTube。Firefox ZIP 仅供临时安装，不代表已签名 XPI 或商店审核通过。

Google Cast 仍为实验功能。用户确认一段 Google 官方演示可在 Shield 播放；这不验证其他来源或私人文件。Shield 本地文件请使用 Chrome 标签页投屏。Windows Chrome 不支持 AirPlay。

Gofile、MegaUp、1fichier、Turbobit 分享和 pCloud 上传链接均为可选功能。仅在您点击后发送。协议经过本地测试；真实上传尚未验证。须遵守服务商的容量和保留期限。

本地构建实验性检测 YouTube 并处理分离轨道/SABR。提供的一个 Short 已以 144p/720p 完整保存音视频；其他视频、画质和会话需单独验证。Store ZIP 不包含 YouTube。请启动正常播放器；SABR 中断后从头开始。不保证兼容所有网站。

## 0.1.52

TikTok 使用当前帖子的原生媒体元数据，每种画质最多保留三个原始 CDN 地址。地址失败后，只有通过检查的备用地址才能替换它；保留所选画质和标题。遇到服务器限流仍需等待。保存完成前，请保持来源页面和管理器打开。

## 0.1.51

可直接在视频旁编辑裁剪时间：输入秒数、m:ss 或 h:mm:ss，最多保留三位小数。拖动手柄与输入框保持同步；无效时间范围无法导出。分段下载停止其他请求时会保留最初的错误原因。服务器限流仍需等待，不会绕过限制。

## 0.1.50

直接文件、HLS 和 DASH 的下载建议与图标计数会在有界媒体前缀检查后出现：后台最多同时进行两项检查，无需打开弹窗。不确定的来源暂不显示，可通过“扫描页面”重试。真实检查覆盖指定的 Instagram Reel（不含推荐内容）、TikTok 和 Odysee。访问限制与验证挑战会明确显示；Odysee 完整下载尚未验证。可用时显示容器尺寸。一致的 HTTP 总大小描述完整来源；≈ 表示估计值，绝不把 HLS 初始化片段的大小当作整部视频大小。缺失的元数据仍标为未知。本地 YouTube SABR、播放列表和捕获原型保留各自的验证范围；此预检查不认证其媒体字节。兼容性仍有限。

## 0.1.49

同一 HLS 点播视频的独立音频和视频源会在轨道检查后合并显示。一条下载建议保留可用画质，并合并两条轨道。不进行额外的 URL 规范化；其他格式和播放器仍受已说明的限制。

## 裁剪画面 — 0.1.48

选择视频区域并导出为新的 MP4。原文件会保留。

拖动以绘制新区域。在区域内拖动可移动，使用控制柄可调整大小。方向键每次移动 1 像素，按住 Shift 则移动 10 像素。

## 0.1.46

新增的 HLS 点播重复源会在比较下载计划和字节样本后合并，并保留播放器的原始 URL。可选的 2/4/8 连接设置可同时下载兼容的 DASH 音频和视频轨道。拆分单个资源需要强版本校验器和可靠的字节范围支持。速度取决于服务器和网络连接。

## VK Video — 0.1.43

VK Video：兼容的 DASH 视频显示为一个来源，可选择画质。播放分片和界面提示音会被排除。Alcydeo 合并已声明的音视频资源，保存经过检查的 MP4。提供的 7 分 53 秒视频已以 144p（AV1/Opus）保存并完整解码。并非所有编解码器、直播、私有内容和 DRM 都受支持。处理期间请保持管理器打开。

## X — 0.1.38

X 帖子：更新 Alcydeo 后请刷新帖子。即使播放器使用 Blob，原生数据也提供标题和 MP4 画质。读取新旧启动数据时不执行脚本。有完整文件时，不单独列出音频和视频播放列表。提供的帖子已保存为 57.6 秒 AVC/AAC MP4 并完整解码。不保证所有动态流、私密帖子、直播或布局。无需新增权限、账号、API 或辅助程序。

## TikTok — 0.1.37

TikTok 帖子：即使播放器使用 Blob，Alcydeo 也读取当前帖子的原生目录，将画质和编码归为一张卡片并保留真实标题。源标签页检查并流式传输原始文件到本地处理，不修改请求头或签名，也无需辅助程序。保持 TikTok 和管理器打开，弹窗可关闭。中断的文件会从头开始。提供的 33 秒 AVC/AAC 视频已完整保存和解码；不保证所有动态流、直播、私密帖子、编码或页面布局。

## YouTube 播放列表 — 0.1.38

仅限本地构建：YouTube 播放列表中可用视频默认勾选。取消不需要的视频，选择最高画质后开始。文件逐个保存到以播放列表命名的子文件夹，保留原始序号和视频标题。可关闭弹窗，但须保持管理器打开；继续时跳过已保存文件，失败项目可单独重试。开始前须加载完整元数据（最多 5,000 项／100 页）。使用原生续页数据和一个自有静音播放标签，不绕过访问限制。尚未验证真实 YouTube 完整播放列表的传输。Store 包不含此功能。

## 保存直播流

直接保存收到的 HLS 分段，保留源质量。支持未加密、音视频在同一流中的 TS/fMP4。请保持管理器打开。其他来源可使用标签页录制。

从最近的完整分段开始，可能包含点击前几秒。停止并保存会完成当前分段，再生成经过检查的 MP4。不会恢复更早的直播内容。

此直播的音频单独传输。请选择音视频合一的 HLS 来源或标签页录制；不会保存缺少原音轨的视频。

直播录制已中断。可保存已接收的部分，无法恢复错过的直播时段。

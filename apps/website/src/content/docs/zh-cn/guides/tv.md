## 投放

请在 Chrome 接收设备选择器中选择电视。保持此标签页打开以控制播放。

电视会收到完整流并选择兼容的画质和音轨。

原生 Cast 取决于 Chrome、接收设备和媒体格式。Alcydeo 不添加中继服务器。直接播放不适用时，投放标签页可使用原网站播放器。

接收设备未能加载视频。链接可能需要 Cookie、已过期或格式不支持。请改为投放原标签页。

20 s — 接收设备未及时确认播放。请重试或投放原标签页。

## 投放原标签页

返回原标签页并播放视频，然后打开 Chrome ⋮ → 投放、保存和分享 → 投放… → 来源 → 投放标签页，选择电视。此选择器需从 Chrome 菜单打开。

请使用同一本地网络中的 Google Cast 兼容设备。若 Chrome 也无法发现，请检查网络、VPN 和防火墙。

## 如何投放此播放器

1. 在 Alcydeo 中打开视频文件并开始播放。
2. 打开 Chrome ⋮ → 投放、保存和分享 → 投放…。此按钮显示步骤，接收设备选择器需从 Chrome 菜单打开。
3. 在“来源”中选择“投放标签页”，再选择电视，例如 NVIDIA SHIELD。

请保持此标签页打开。使用播放器控制播放，通过 Chrome 投放按钮停止投放。投放标签页可能比发送视频链接占用更多 CPU。

文件保留在电脑上；Chrome 原生投放会将媒体传输给所选接收设备。Alcydeo 不会将其上传至托管服务。

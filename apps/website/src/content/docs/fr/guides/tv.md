## Caster

Choisissez votre TV dans le sélecteur de Chrome. Gardez cet onglet ouvert pour les commandes de lecture.

La TV reçoit le flux complet et choisit une qualité et une piste audio compatibles.

Cast natif dépend de Chrome, du récepteur et du format vidéo. Alcydeo n’ajoute aucun serveur relais. La diffusion d’onglet utilise le lecteur du site lorsque la lecture directe ne convient pas.

Le récepteur n’a pas chargé la vidéo. Le lien peut nécessiter des cookies, avoir expiré ou utiliser un format incompatible. Castez l’onglet d’origine.

20 s — Le récepteur n’a pas confirmé la lecture à temps. Réessayez ou castez l’onglet d’origine.

## Caster l’onglet d’origine

Revenez dans l’onglet d’origine, lancez la vidéo, puis ouvrez le menu ⋮ de Chrome → Caster, enregistrer et partager → Caster… → Sources → Caster l’onglet. Choisissez votre TV. Ce sélecteur s’ouvre depuis le menu Chrome.

Utilisez un récepteur compatible Google Cast sur le même réseau local. Si Chrome ne le trouve pas non plus, vérifiez le réseau, le VPN et le pare-feu.

## Comment caster ce lecteur

1. Ouvrez votre fichier vidéo dans Alcydeo et lancez sa lecture.
2. Ouvrez le menu ⋮ de Chrome → Caster, enregistrer et partager → Caster…. Ce bouton affiche les étapes ; le sélecteur de TV s’ouvre depuis le menu Chrome.
3. Dans Sources, choisissez Caster l’onglet, puis votre TV, par exemple NVIDIA SHIELD.

Gardez cet onglet ouvert. Utilisez le lecteur pour la lecture et le bouton Cast de Chrome pour arrêter la diffusion. Diffuser l’onglet peut consommer davantage de CPU qu’envoyer un lien vidéo.

Les fichiers restent sur ce PC ; Cast natif de Chrome transmet le média au récepteur choisi. Alcydeo ne l’envoie pas à un hébergeur.

title: "Локальная установка"
---

Выберите пакет для настольного Chrome или Firefox. Аккаунт Alcydeo и дополнительное ПО не нужны. Официальных страниц в магазинах пока нет.

[Скачать Alcydeo](https://github.com/drslid/Alcydeo/releases/tag/v1.0.0) — v1.0.0

1. Скачайте ZIP для Chrome из GitHub Releases и распакуйте в постоянную папку.
2. Откройте chrome://extensions, включите режим разработчика и выберите Загрузить распакованное расширение. Укажите папку с manifest.json.
3. Закрепите Alcydeo и обновите страницу видео. Начните воспроизведение, откройте расширение и выберите доступное качество.

### Firefox

Firefox 153+: загрузите ZIP через about:debugging → Этот Firefox → Загрузить временное дополнение. Установка действует до перезапуска Firefox; постоянная установка требует подписи Mozilla.

У Firefox 153+ отдельный пакет без YouTube. Захват вкладки Chrome, Google Cast и AirPlay в Firefox недоступны. Локальная обработка зависит от его кодеков; проверенный охват указан в руководстве Firefox.

Пакет Chrome для разработки включает экспериментальный YouTube. Подготовка для Chrome Web Store и пакет Firefox исключают YouTube. Установка ZIP в Firefox временная; подписанный XPI и одобрение магазина не заявлены.

Новая установка или сброс настроек: четыре одновременных файла, многопоточная загрузка включена с четырьмя соединениями на совместимый файл. Прежние настройки сохраняются. Оба предела регулируются; универсальное ускорение не обещается.

### GitHub / MIT

Node 24.22.2 · pnpm 12.5.1

```sh
git clone https://github.com/drslid/Alcydeo.git
cd Alcydeo
pnpm install --frozen-lockfile
pnpm build:chrome
pnpm build:firefox
```

Chrome: `apps/extension/.output/chrome-mv3`

Firefox: `apps/extension/.output/firefox-mv3`

После обновления перезагрузите Alcydeo и уже открытые страницы видео. Версия 0.1.39 останавливает старые наблюдатели при исчезновении обмена сообщениями Chrome и исправляет ошибку sendMessage/недействительного контекста. Старые ошибки можно очистить в панели ошибок расширения.

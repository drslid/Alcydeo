Конвертация в MP4

MP4 с видео H.264 и аудио AAC. По одному файлу; оставьте менеджер открытым. Оригинал сохраняется. Совместимые дорожки копируются, остальные поддерживаемые дорожки перекодируются. Это может занять время и изменить качество.

Качество видео: Авто · копировать совместимое видео / Высокое качество / Сбалансированное / Меньший размер.

Максимальное разрешение: Исходное · без увеличения / 1080p / 720p / 480p.

Битрейт аудио: Авто · копировать совместимый AAC / 128 / 192 / 256 kb/s.

Параметры MP4 по умолчанию. Изменение качества, разрешения или звука может потребовать перекодирования. Размер и скорость зависят от исходника и компьютера.

Конвертация выполняется локально. Копия выбранного исходника и MP4 остаются во временном хранилище браузера до удаления задачи. Оригинал на диске сохраняется. Содержимое файлов не отправляется на сервер.

Файлы конвертируются по одному. После паузы или закрытия менеджера конвертация начнётся заново из сохранённого исходного файла.

## Одновременные загрузки — 1.0.0

Новая установка или сброс настроек: четыре одновременных файла, многопоточная загрузка включена с четырьмя соединениями на совместимый файл. Прежние настройки сохраняются. Оба предела регулируются; универсальное ускорение не обещается.

Файлов одновременно: 1 / 2 / 3 / 4 / 5 / 6 / 7 / 8.

От 1 до 8 файлов одновременно, независимо от числа соединений на файл. Файлы из очереди начинают загружаться, как только освобождается место.

Снижение лимита не прерывает текущие загрузки. Конвертация по-прежнему выполняется по одному файлу.

### Многопоточная загрузка

Несколько соединений для совместимых файлов и DASH.

Соединений на файл: 2 / 4 / 8.

Не закрывайте менеджер. Совместимые аудио- и видеодорожки могут загружаться одновременно. Для разделения одного ресурса нужны надёжные диапазоны байтов и строгий валидатор версии; иначе используется обычная передача. Скорость зависит от сервера и соединения.

## Записать поток

Прямой эфир — Поддерживаемый HLS эфир записывается напрямую. Для других плееров используется запись вкладки.

Поток плеера — Сохраняйте сегменты HLS напрямую с исходным качеством. Поддерживаются незашифрованные TS/fMP4 с аудио и видео в одном потоке. Не закрывайте менеджер. Для других источников используйте захват вкладки.

Начинает с недавнего полного сегмента, возможно за несколько секунд до нажатия. Остановка завершает текущий сегмент и создаёт проверенный MP4. Более ранняя часть эфира не восстанавливается.

У этого эфира отдельное аудио. Выберите объединённый HLS или захват вкладки; файл с потерянной аудиодорожкой не сохраняется.

Запись эфира прервана. Сохраните полученную часть; пропущенное время эфира не восстанавливается.

Захват вкладки — Записывайте вкладку из окна расширения или выберите экран здесь. Повышенный битрейт и разрешение до исходного. Оставьте менеджер открытым.

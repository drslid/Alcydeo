Локальный эксперимент YouTube хранит ограниченный наблюдаемый контекст и существующие непрозрачные транспортные токены вместе с задачей на устройстве. Аттестации не создаются, удалённый код не выполняется. Экспорт исключает эти данные.

Без телеметрии. Медиатека и задачи остаются в браузере. Сетевой доступ только к разрешённым источникам.

Автоматическое обнаружение медиа

Включено по умолчанию. Chrome предоставляет доступ к сайтам при установке. Здесь можно приостановить обнаружение или ограничить доступ в Chrome.

Alcydeo может автоматически повторно читать обнаруженные плейлисты для определения качества и сегментов. Расширение скачивает медиасегменты только после запуска загрузки пользователем.

Задачи локально хранят URL страниц и источников, включая временные подписи, в IndexedDB. Фрагменты и результаты используют OPFS. Удаление задачи очищает запись и временные файлы, но не итоговый файл и историю Chrome. Экспорт не содержит URL, путей и идентификаторов загрузки. Запросы обращаются к разрешённым источникам/CDN с применимыми сессиями Chrome. Инкогнито отключён. Будущий хост GitHub Pages может журналировать посещения сайта. Публичный контакт пока не указан.

Очистить историю

Из Alcydeo будут удалены записи завершённых, неудачных и отменённых загрузок и их временные файлы на всех страницах и при любых фильтрах, включая избранное. Сохранённые файлы, активные и приостановленные загрузки останутся.

При наличии полного файла списки аудио и видео не предлагаются отдельно. Предоставленный ролик сохранён как MP4 AVC/AAC на 57,6 секунды и полностью декодирован. Все ленты, закрытые публикации, эфиры и интерфейсы не проверены. Новые разрешения, аккаунт, API или помощник не нужны.

## TikTok — 0.1.37

Публикации TikTok: Alcydeo читает штатный каталог выбранного видео даже с Blob-плеером, объединяя качество и кодеки под настоящим заголовком. Исходная вкладка проверяет и передаёт оригинал в локальную обработку без изменения заголовков/подписей и без помощника. TikTok и менеджер должны быть открыты; всплывающее окно можно закрыть. Прерванный файл начинается заново. Предоставленный ролик AVC/AAC на 33 секунды сохранён и полностью декодирован; все ленты, эфиры, закрытые публикации, кодеки и интерфейсы не проверены.

Каталог и токены продолжения остаются в IndexedDB и удаляются при навигации или очистке сессии. Выбранные задания хранятся до очистки завершённой истории. Штатный контекст остаётся на странице YouTube; запросы используют сессию браузера. Данные не отправляются на серверы Alcydeo, в облако или документацию.

Конвертация в MP4

MP4 с видео H.264 и аудио AAC. По одному файлу; оставьте менеджер открытым. Оригинал сохраняется. Совместимые дорожки копируются, остальные поддерживаемые дорожки перекодируются. Это может занять время и изменить качество.

Качество видео: Авто · копировать совместимое видео / Высокое качество / Сбалансированное / Меньший размер.

Максимальное разрешение: Исходное · без увеличения / 1080p / 720p / 480p.

Битрейт аудио: Авто · копировать совместимый AAC / 128 / 192 / 256 kb/s.

Параметры MP4 по умолчанию. Изменение качества, разрешения или звука может потребовать перекодирования. Размер и скорость зависят от исходника и компьютера.

Конвертация выполняется локально. Копия выбранного исходника и MP4 остаются во временном хранилище браузера до удаления задачи. Оригинал на диске сохраняется. Содержимое файлов не отправляется на сервер.

Файлы конвертируются по одному. После паузы или закрытия менеджера конвертация начнётся заново из сохранённого исходного файла.

## Записать прямой поток

Сохраняйте сегменты HLS напрямую с исходным качеством. Поддерживаются незашифрованные TS/fMP4 с аудио и видео в одном потоке. Не закрывайте менеджер. Для других источников используйте захват вкладки.

Начинает с недавнего полного сегмента, возможно за несколько секунд до нажатия. Остановка завершает текущий сегмент и создаёт проверенный MP4. Более ранняя часть эфира не восстанавливается.

У этого эфира отдельное аудио. Выберите объединённый HLS или захват вкладки; файл с потерянной аудиодорожкой не сохраняется.

Запись эфира прервана. Сохраните полученную часть; пропущенное время эфира не восстанавливается.

Язык и миниатюры сохраняются локально с записями медиатеки. Миниатюры берутся из доступных реальных файлов. Рисунки остаются в выбранной вкладке и удаляются при остановке записи. Удаление записей очищает временные данные, сохраняя файлы на диске. Запись начинается после явного действия или выбора поверхности в Chrome.

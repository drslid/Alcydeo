## 0.1.47

Собранные файлы, прошедшие проверку структуры, сохраняются автоматически без второго нажатия. Локальное воспроизведение в браузере больше не блокирует сохранение; при отсутствии кодека может понадобиться другой проигрыватель. Прежние ошибки воспроизведения из-за кодека устраняются сохранением без повторной загрузки, если локальный результат цел. После отмены «Сохранить как» по-прежнему требуется явный повтор.

Исходное качество означает, что разрешение источника неизвестно. Источники, распознанные как HTML, удаляются. При обнаруженном перенаправлении плеера название и разрешение связываются с реальным медиафайлом.

Некоторые CDN отдают MP4 как application/octet-stream. Alcydeo сохраняет наблюдаемый итоговый подписанный URL медиа и исключает HTML-страницы проигрывателей, ошибок и HTML-вложения. После перезагрузки расширения перезапустите исходный проигрыватель.

Значок обновляется при обнаружении источника, даже если страница или её фреймы ещё загружаются. Доступные варианты качества добавляются позже. Сайт должен сначала предоставить медиаисточник.

Alcydeo может автоматически повторно читать обнаруженные плейлисты для определения качества и сегментов. Расширение скачивает медиасегменты только после запуска загрузки пользователем.

URL источника может возвращать другой список HLS. Alcydeo проходит единственный вариант до доступных качеств и разрешает выбранный вариант при скачивании, до шести уровней. Если качество исчезло, выберите заново. Зашифрованные источники не поддерживаются.

Временные метаданные (0x15) не включены в сохранённый файл.

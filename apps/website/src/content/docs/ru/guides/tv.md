## Транслировать

Выберите ТВ в окне приёмников Chrome. Оставьте эту вкладку открытой для управления.

ТВ получает полный поток и выбирает совместимые качество и звук.

Нативная трансляция зависит от Chrome, приёмника и формата. Alcydeo не добавляет ретранслятор. Если прямое воспроизведение не подходит, трансляция вкладки использует исходный плеер.

Приёмник не загрузил видео. Ссылка может требовать cookies, истечь или иметь неподдерживаемый формат. Транслируйте исходную вкладку.

20 s — Приёмник не подтвердил воспроизведение вовремя. Повторите попытку или транслируйте исходную вкладку.

## Транслировать исходную вкладку

Вернитесь на исходную вкладку, запустите видео и откройте Chrome ⋮ → Трансляция, сохранение и отправка → Транслировать… → Источники → Транслировать вкладку. Выберите ТВ. Этот выбор открывается из меню Chrome.

Используйте приёмник Google Cast в той же локальной сети. Если Chrome тоже не видит его, проверьте сеть, VPN и брандмауэр.

## Файл с ПК

Воспроизведите файл здесь, затем выберите способ трансляции, поддерживаемый приёмником.

Кнопка Cast для файлов в Chrome поддерживает некоторые устройства Chromecast и Google TV Streamer. Этот API исключает Nvidia Shield; транслируйте вкладку плеера через меню Chrome.

Выбрать видеофайл

Для трансляции нужен необязательный доступ к сохранённому файлу. Файл не загружается на сервер. После подготовки нажмите кнопку трансляции в плеере.

Включите доступ к URL файлов в настройках расширения Alcydeo в Chrome и снова откройте плеер.

Нативной трансляции нужен сохранённый файл. Подготовка откроет «Сохранить как» для локальной копии; оригинал останется.

Для нативного удалённого воспроизведения Chrome нужно видео длиннее 15 секунд. Для этого ролика используйте инструкцию трансляции вкладки.

## Как транслировать этот плеер

1. Откройте видеофайл в Alcydeo и запустите воспроизведение.
2. Откройте Chrome ⋮ → Трансляция, сохранение и отправка → Транслировать…. Эта кнопка показывает шаги; выбор ТВ открывается из меню Chrome.
3. В разделе «Источники» выберите трансляцию вкладки, затем ТВ, например NVIDIA SHIELD.

Оставьте вкладку открытой. Управляйте воспроизведением в плеере, а остановкой трансляции — в Chrome. Трансляция вкладки может сильнее нагружать процессор, чем отправка ссылки.

Файлы остаются на ПК; нативный Cast Chrome передаёт медиа выбранному приёмнику. Alcydeo не загружает их на хостинг.

Поддерживаются прямые файлы и протестированные незашифрованные варианты HLS/DASH. Совместимость зависит от доступа, кодеков и хранилища. Защищённые медиа отклоняются. Для сегментов нужно примерно втрое больше временного места; не все большие файлы проверены.

Google Cast остаётся экспериментальным. Пользователь подтвердил один официальный ролик Google на Shield; это не подтверждает другие источники и личные файлы. Для локальных файлов на Shield используйте трансляцию вкладки Chrome. AirPlay в Chrome для Windows недоступен.

Gofile, MegaUp, 1fichier, Turbobit и ссылки загрузки pCloud необязательны. Отправка начинается только по вашему нажатию. Протоколы проверены локально; реальные отправки не подтверждены. Действуют ограничения и сроки хранения провайдера.

Локальная сборка экспериментально распознаёт YouTube и обрабатывает отдельные дорожки/SABR. Предоставленный Short полностью сохранён в 144p/720p со звуком и видео; другим видео, качествам и сеансам нужна отдельная проверка. ZIP Store исключает YouTube. Запустите обычный проигрыватель; прерванный SABR начинается заново. Универсальная совместимость не обещается.

## 0.1.52

TikTok использует исходные медиаданные текущего поста и сохраняет до трёх оригинальных адресов CDN для каждого качества. Неработающий адрес заменяется только после проверки альтернативы; выбранные качество и название сохраняются. При ограничении сервера нужно подождать. Оставьте страницу источника и менеджер открытыми до сохранения.

## 0.1.51

Время обрезки редактируется рядом с видео: секунды, m:ss или h:mm:ss с точностью до трёх знаков после запятой. Ползунки и поля синхронизированы; неверный интервал нельзя экспортировать. При остановке остальных запросов сегментная загрузка сохраняет исходную причину ошибки. При ограничении сервера нужно подождать; обход не выполняется.

## 0.1.50

Предложения и счётчик прямых файлов, HLS и DASH появляются после ограниченной проверки начальных байтов: не более двух фоновых проверок одновременно, без открытия окна. Неопределённые источники скрыты; Сканировать страницу повторяет проверку. Реальные тесты охватывают точный Instagram Reel без рекомендаций, TikTok и Odysee. Ограничения и проверки доступа показываются явно; полная загрузка Odysee пока не подтверждена. Размеры кадра из контейнера отображаются при наличии. Согласованные общие размеры HTTP относятся ко всему источнику; ≈ означает оценку, а не размер одной инициализации HLS. Отсутствующие метаданные остаются неизвестными. Локальные прототипы YouTube SABR, плейлистов и захвата сохраняют отдельные пределы проверки; эта предварительная проверка не подтверждает их байты. Совместимость остаётся ограниченной.

## 0.1.49

Раздельные источники аудио и видео одного HLS VOD объединяются после проверки их дорожек. Один вариант загрузки сохраняет доступные качества и объединяет обе дорожки. Дополнительная нормализация URL не применяется; для других форматов и проигрывателей сохраняются описанные ограничения.

## 0.1.46

Дополнительные дубликаты HLS VOD объединяются после сравнения плана загрузки и образцов байтов; исходный URL проигрывателя сохраняется. Необязательная настройка 2/4/8 соединений позволяет одновременно загружать совместимые аудио- и видеодорожки DASH. Для разделения одного ресурса нужны сильный валидатор версии и надёжные диапазоны байтов. Скорость зависит от сервера и соединения.

## VK Video — 0.1.43

VK Видео: совместимые DASH-видео отображаются одной записью с выбором качества. Фрагменты воспроизведения и звуки интерфейса исключаются. Alcydeo объединяет объявленные видео- и аудиоресурсы и сохраняет проверенный MP4. Предоставленное видео длительностью 7 мин 53 с сохранено и полностью декодировано в 144p (AV1/Opus). Не все кодеки, эфиры, закрытые видео и DRM поддерживаются. Не закрывайте менеджер во время обработки.

## X — 0.1.38

Публикации X: обновите страницу после обновления Alcydeo. Штатные данные дают заголовок и варианты MP4 даже для Blob-плеера. Новые и старые загрузочные данные читаются без выполнения скриптов. При наличии полного файла списки аудио и видео не предлагаются отдельно. Предоставленный ролик сохранён как MP4 AVC/AAC на 57,6 секунды и полностью декодирован. Все ленты, закрытые публикации, эфиры и интерфейсы не проверены. Новые разрешения, аккаунт, API или помощник не нужны.

## TikTok — 0.1.37

Публикации TikTok: Alcydeo читает штатный каталог выбранного видео даже с Blob-плеером, объединяя качество и кодеки под настоящим заголовком. Исходная вкладка проверяет и передаёт оригинал в локальную обработку без изменения заголовков/подписей и без помощника. TikTok и менеджер должны быть открыты; всплывающее окно можно закрыть. Прерванный файл начинается заново. Предоставленный ролик AVC/AAC на 33 секунды сохранён и полностью декодирован; все ленты, эфиры, закрытые публикации, кодеки и интерфейсы не проверены.

## Плейлист YouTube — 0.1.38

Только локальная сборка: доступные видео плейлиста YouTube выбраны по умолчанию. Снимите ненужные отметки, задайте предел качества и начните. Файлы сохраняются по одному в подпапку с названием плейлиста, исходной позицией и названием видео. Держите менеджер открытым; всплывающее окно можно закрыть. Продолжение пропускает сохранённые файлы, ошибки можно повторить отдельно. До старта загружаются все метаданные (до 5000 элементов / 100 страниц). Используются штатные продолжения и одна собственная вкладка плеера без звука, без обхода доступа. Полная загрузка реального плейлиста YouTube не проверена. Пакет Store исключает эту функцию.

Конвертация в MP4

MP4 с видео H.264 и аудио AAC. По одному файлу; оставьте менеджер открытым. Оригинал сохраняется. Совместимые дорожки копируются, остальные поддерживаемые дорожки перекодируются. Это может занять время и изменить качество.

Качество видео: Авто · копировать совместимое видео / Высокое качество / Сбалансированное / Меньший размер.

Максимальное разрешение: Исходное · без увеличения / 1080p / 720p / 480p.

Битрейт аудио: Авто · копировать совместимый AAC / 128 / 192 / 256 kb/s.

Параметры MP4 по умолчанию. Изменение качества, разрешения или звука может потребовать перекодирования. Размер и скорость зависят от исходника и компьютера.

Конвертация выполняется локально. Копия выбранного исходника и MP4 остаются во временном хранилище браузера до удаления задачи. Оригинал на диске сохраняется. Содержимое файлов не отправляется на сервер.

Файлы конвертируются по одному. После паузы или закрытия менеджера конвертация начнётся заново из сохранённого исходного файла.

## Записать прямой поток

Сохраняйте сегменты HLS напрямую с исходным качеством. Поддерживаются незашифрованные TS/fMP4 с аудио и видео в одном потоке. Не закрывайте менеджер. Для других источников используйте захват вкладки.

Начинает с недавнего полного сегмента, возможно за несколько секунд до нажатия. Остановка завершает текущий сегмент и создаёт проверенный MP4. Более ранняя часть эфира не восстанавливается.

У этого эфира отдельное аудио. Выберите объединённый HLS или захват вкладки; файл с потерянной аудиодорожкой не сохраняется.

Запись эфира прервана. Сохраните полученную часть; пропущенное время эфира не восстанавливается.

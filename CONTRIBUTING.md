# Contributing

Read AGENTS.md, docs/SPEC.txt, docs/REFERENCES.txt and docs/design-tokens.json before product changes. Keep original code MIT and preserve dependency licenses. Do not add telemetry, a native companion, account backend or remote executable code.

Use the pinned tools and scripts documented in docs/DEVELOPMENT.md. Include real media-output validation for engine changes, extension-loaded browser tests for runtime behavior, native localization parity and real screenshots for UI changes. Label untested capabilities honestly. Use original/authorized media; never commit signed URLs, cookies, private files, signing keys or reference CRX contents.

Publication is separate from local development. Do not create a remote, release, Pages deployment or Store submission without an explicit instruction from the project owner.

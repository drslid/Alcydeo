# Alcydeo 1.0.0 — Chrome and Firefox

Find available video/audio, choose a quality, save it and keep your files in a local Library. Alcydeo 1.0.0 adds a dedicated Firefox package, moves diagnostics into the dashboard, changes the initial download defaults and corrects the kingfisher's back across the shared identity.

## Install

**Chrome desktop:** download the Chrome ZIP and extract it to a folder you will keep. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the folder containing `manifest.json`. Start or refresh a video page, let its normal player run, then choose an available quality in Alcydeo.

**Firefox 153 or later on desktop:** download the Firefox ZIP. Open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on…**, and select the ZIP, or its `manifest.json` after extraction. This installation lasts until Firefox restarts. Permanent installation in ordinary Firefox requires Mozilla signing; renaming a ZIP to `.xpi` does not sign it. See the [Firefox guide](https://github.com/drslid/Alcydeo/blob/v1.0.0/docs/FIREFOX.md) for the exact tested scope.

Keep the persistent manager open for segmented processing, multipart and video editing. The popup may close. Closing the browser stops processing; recovery depends on the source and confirmed local state. Wait for active work before updating. In Chrome, replace files in the **same folder** and reload its card to preserve the extension identity and Library. Refresh source pages as well.

## What changed

- **Firefox has its own package.** It uses a dedicated browser runtime and excludes YouTube, matching the AMO-preparation channel. Browser-specific capabilities and tests are documented, with no parity claim from compiling alone.
- **Diagnostics move to the dashboard.** Open **Library → Settings → Detection**, choose the source tab, then inspect or copy its local report. It retains safe codes/counters without automatic upload; the popup focuses on media and downloads.
- **Four files at once by default.** New installations and a settings reset select four simultaneous files and enable multipart with four connections per compatible file. Existing saved choices are preserved. The file limit remains 1–8 and connections per compatible file remain 2/4/8; source validators and global admission still apply.
- **A natural kingfisher contour.** Remove the rounded rear lobe and dark patch; the streamlined silhouette is shared by the emblem, monochrome, icons, signatures and selected proposal, without changing the face, wing or palette.
- **Matching publication guidance.** English/French README, ten-language Pages installation and limits, separate browser/Store/source assets and clear Firefox signing instructions.

## Browser differences and limits

Firefox does not have Chrome's tab-capture or Google Cast APIs, and no AirPlay capability is claimed. Local processing depends on available codecs and storage; unsupported combinations keep the original and give an error. Chrome results do not establish Firefox media-output parity.

The Chrome development channel's YouTube experiment remains partial. The separate Chrome Store preparation and Firefox package exclude YouTube. Protected media, challenges, attestations and explicit source refusals are not bypassed; there is no promise of every site, resolution or multi-GB file working.

Cloud destinations are voluntary and retain their provider-specific limits. Local/intercepted protocol tests and real initialization checks do not establish successful real-file uploads to every provider. No upload begins without **Send**.

Google Cast remains a Chrome experiment. The user confirmed one official Google demo on Nvidia Shield; the laboratory has no physical receiver. Other sources, direct TikTok reception and private PC file transport to Shield are not validated by that result. Use the explicit Chrome tab-casting guide for local files; AirPlay is unavailable in Windows Chrome. No companion, relay or private-file upload is introduced.

## Français

La 1.0.0 fournit un paquet Chrome, un paquet Firefox distinct sans YouTube, les sources de revue et les supports mis à jour. **Chrome :** décompressez le ZIP puis utilisez `chrome://extensions` → **Mode développeur → Charger l’extension non empaquetée**. **Firefox :** chargez son ZIP dans `about:debugging` → **Ce Firefox → Charger un module complémentaire temporaire** ; il reste installé jusqu’au redémarrage. Le dos du martin-pêcheur est corrigé dans les déclinaisons.

Firefox n’ajoute ni capture d’onglet Chrome, ni Google Cast, ni AirPlay. Les codecs, accès source, fournisseurs Cloud et récepteurs gardent leurs limites documentées. La Release 1.0.0 ne constitue aucune approbation Google/Mozilla ni garantie tous sites. Les soumissions Store et la signature Firefox restent des actions séparées.

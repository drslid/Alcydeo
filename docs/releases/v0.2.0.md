# Alcydeo 0.2.0 — first public preview

Alcydeo is a free Chrome desktop extension for finding available web video/audio, saving selected sources and organizing or editing files locally. This first public preview brings the existing media workflow to GitHub with a new original kingfisher identity, ten-language documentation and tested development packages.

**Documentation:** https://drslid.github.io/Alcydeo/ · **Français:** https://drslid.github.io/Alcydeo/fr/ · **Support:** https://github.com/drslid/Alcydeo/issues

## Choose your download

| Asset | Use |
| --- | --- |
| `alcydeo-0.2.0-chrome.zip` | Chrome development preview, including experimental local YouTube detection/playlist capabilities |
| `alcydeo-store-0.2.0-chrome.zip` | Separate Chrome Web Store preparation; all YouTube catalog/transport/playlist code is excluded |
| `alcydeo-brand-0.2.0.zip` | Original vector emblem, signatures, favicon/toolbar icons, high resolution exports and alternative logo proposals |
| `ffmpeg-aac-corresponding-source-60a2818.tar.gz` | Corresponding source for the embedded AAC codec; distributed alongside the binaries under its LGPL terms |
| `SHA256SUMS` | Checksums for these downloadable files |

Neither extension ZIP is an official Chrome Web Store installation. GitHub's automatically generated “Source code” archives are for development and are not an installable extension.

## Install in Chrome

1. Download the desired extension ZIP and extract it to a permanent folder. `manifest.json` must be directly inside that folder.
2. Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the extracted folder.
3. Open or refresh a video page, let its normal player start and open Alcydeo. Choose the available quality and download.
4. Keep the source page and persistent manager open for the contextual or segmented jobs that need them. The popup can close safely.

For an existing development install, update and reload the **same folder** to preserve its extension identity and Library. Keep original media files while trying editing tools.

## Included in this preview

- Automatic DOM/network detection, validated-source badge and grouped qualities; HTML responses and known failed sources are not offered as completed videos.
- Direct downloads plus supported unencrypted HLS/DASH VOD profiles, persistent task state, bounded retry/cancellation and automatic disk saving after the applicable checks.
- A unified Library with real thumbnails when the local file is accessible, selection, search/favorites, editing/Cloud actions and reveal in folder.
- Local visual trim/crop/merge, conversion to supported MP4 H.264/AAC and compression. Originals are retained and output names keep meaningful suffixes.
- Separate recording modes for supported live HLS and explicit tab capture, with local annotation controls.
- Independent controls for compatible connections per file and up to eight simultaneous source files. Conversion remains one at a time.
- English, Spanish, French, German, simplified Chinese, Arabic, Russian, Portuguese, Hindi and Urdu, including manual flags and Arabic/Urdu RTL.
- An optional external Google Cast player with integrated controls and an explicit original-source handoff from Library. Its official SDK stays outside the extension.
- The original **Le Plongeon** kingfisher emblem, a consistent brand kit, an English/French README and a Pages presentation inspired by NoxRouteNeo.

## Read the limits before trying

This is a **pre-release**, not universal compatibility or feature parity. Source access, signatures, codecs and browser capabilities vary. DRM, access challenges and explicit server refusals are not bypassed.

Cloud providers are optional. The current Gofile/pCloud/MegaUp/1fichier/Turbobit connectors have protocol tests, with real-upload validation still limited. Sending is an explicit user action and makes the selected file subject to its provider's policies.

The user reports that one official Google sample plays on Nvidia Shield. The laboratory has no physical receiver; simulated SDK states and successful browser controls do not establish TV playback for other media. **Direct Cast of private PC file bytes to Shield is not implemented. AirPlay is unavailable in Windows Chrome.** A checked original online source may be reused; edited/captured outputs are never replaced by the unedited original.

YouTube experiments belong only to the development preview and remain partial. No acceptance by Google or Mozilla is claimed. Chrome Web Store submission and a real Firefox/AMO port are later stages, not included here.

## Validation and source

The publication report in `docs/TEST-RESULTS.md` records the exact executed unit/browser/build checks and their limits. Original synthetic fixtures are used for screenshots and file validation. Dependency audit and publication hygiene findings are documented in `docs/DEPENDENCY-REVIEW.md`.

Alcydeo's original code/artwork is MIT. Third-party notices, MPL source archives and AAC adaptation details are inside the extension package. No account backend, telemetry, native companion or remote executable is added to the extension.

## Français — première préversion publique

Alcydeo permet de repérer des médias accessibles, choisir une qualité, les enregistrer et organiser ou modifier les fichiers localement. Cette version publie le code, la documentation dans dix langues et une nouvelle identité martin-pêcheur originale.

Pour essayer : télécharger le ZIP Chrome, l'extraire, puis utiliser **chrome://extensions → Mode développeur → Charger l'extension non empaquetée**. Le ZIP nommé **store** est une préparation distincte sans YouTube ; il ne constitue pas une installation officielle du Chrome Web Store. Sur une installation existante, recharger le même dossier pour garder son identité et sa Bibliothèque.

Les formats, sources et services pris en charge ont des limites détaillées ci-dessus et dans la documentation. Cast depuis un fichier privé du PC vers Shield n'est pas implémenté ; AirPlay n'est pas disponible dans Chrome Windows. Les essais Cloud et SDK simulés ne valent pas validation réelle de tous les fournisseurs ou récepteurs.

Les prochaines étapes sont la validation/soumission Chrome Web Store, puis un véritable portage Firefox testé avant toute publication AMO. Aucune soumission à ces Stores n'est réalisée par cette Release.

Publish the approved logo correction, manager diagnostics, four-file/multipart defaults, and genuinely tested Chrome/Firefox packages with README, Pages and a Nidomark-style GitHub Release. Prepare Store submissions without submitting or signing on either Store.

2. Port to Firefox MV3 event pages and native Promise APIs. Guard unavailable capture/TV APIs, retain source/security checks and bounded media processing. Test an actual temporary Firefox installation, detection/quality/download/file bytes, supported OPFS flows and honest capability states.
3. Update version 1.0.0 and Chrome/Store/Firefox packaging. Validate manifests, bundled code/licenses, YouTube channel boundaries and reproducible Mozilla sources.
4. Update EN/FR README, ten-language site, changelog, reviewer guidance and exact validation reports. Build and visually verify actual interfaces.
5. Publish reviewed commits, manually deploy Pages, verify public assets, then publish a v1.0.0 Release with ZIPs/sources/checksums. Preserve earlier release assets and private keys. No Google/Mozilla Store upload or signing.

Native Chrome tabCapture and Cast are not portable APIs; expose only verified capabilities. No companion/backend added.

## Travail

Vérifier l’état Git et les versions des outils, utiliser un Node LTS compatible et préserver les modifications existantes. Faire un plan bref, puis implémenter une tranche complète avant d’élargir. Ne pas redemander les choix déjà confirmés.

Mettre en œuvre des commandes réelles de typecheck, lint, tests, build extension, ZIP Chrome et build du site. Exécuter les contrôles adaptés aux changements. Tester les parcours médias, l’arrêt du worker, les permissions, les langues/RTL et les fichiers produits ; distinguer tests exécutés et indisponibles. Inspecter visuellement les états de la popup.

Pour les essais sur les lecteurs publics, utiliser un bloqueur de publicités officiel dans un profil de test isolé, à la demande de l’utilisateur. Consigner sa version, son mode et ses listes ; distinguer les essais sans bloqueur. Le bloqueur sert au test, n’est pas embarqué dans Alcydeo et ne change pas les réglages du profil utilisateur.
